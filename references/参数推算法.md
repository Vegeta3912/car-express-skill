# 整车布置硬点定义与推算法

## 硬点定义（SAE J1100 / 行业通用）

| 硬点 | 定义 | 大型 SUV 典型值 |
|---|---|---|
| L101 | 轴距，前轮心→后轮心纵向距 | — |
| L113 | 前轮心 → 加速踏板点（BOF）纵向距，Dash-to-Axle | 850–1050mm |
| L115-2 | 第二排 SgRP（R点）→ 后轮心纵向距 | 400–650mm |
| L50-2 | 前/后排 SgRP 距离 | 950–1050mm |
| H30 | SgRP → 踵点基准（AHP/FRP）垂直距，坐姿高度 | 315–360mm |
| H61 | SgRP 沿后倾 8° 至首个限制面 + 102mm，头部空间 | 1000–1070mm |
| H5 | SgRP 离地高度 | 700–760mm |

## A 类 · 基于官方精确参数的几何推算（可严格复现）

### 0. 前后悬自洽校验
```
前悬 + 轴距 + 后悬 == 车长
```
不等则说明数据口径有问题，先解决再算。例：975+3105+1110=5190 ✓

### 1. 轮胎直径
```
轮胎直径 = 轮辋直径(inch)×25.4 + 2 × 胎宽(mm) × 扁平比/100
```
例 255/50R20 = 508 + 2×255×0.50 = 763mm。
注意前后鸳鸯胎：后轮更宽时直径更大（如后 275/50R20 ≈ 783mm），要分别算。

### 2. 保险杠下沿离地（由接近/离去角反推）
```
前保下沿高 = (前悬 − 前轮半径) × tan(接近角)
后保下沿高 = (后悬 − 后轮半径) × tan(离去角)
```
例 (975−382)×tan18° ≈ 193mm。可与最小离地间隙 + 空悬行程交叉验证。

### 3. 轴荷（重心位置假设法）
```
前轴荷 = 整备质量 × (1 − 重心占轴距比例)
后轴荷 = 整备质量 × 重心占轴距比例
```
重心比例取 0.44–0.46（前置动力/电池车偏前）。必须标注"基于重心假设的推算"。
工信部原始公告若有轴荷字段优先用官方值。

### 4. 迎风面积
```
迎风面积 ≈ 车宽(m) × 车高(m) × 造型系数(0.80–0.88)
```
与风阻系数 Cd 相乘可估算行驶阻力。

## B 类 · 车内硬点（区间估算，不伪造精确值）

发布会现场图为前45度或有模特/展车重叠，**带透视和遮挡，不能作比例尺精确测量 L113/H30/H61**。
即使有正侧图，加速踏板点、R点、踵点都在车内，外观图看不到。

正确做法：
1. 查 SAE 定义，确认硬点含义（不要凭印象）。
2. 取同级同类车典型区间（上表）。
3. 用本车已知约束收敛：如前悬长（975mm）→ L113 偏上限；轴距 3105mm → L50-2 约 1000mm。
4. 输出**区间 + 中值**，标"区间估算/推算"，并在方法说明里写清楚"需整车布置剖面图或三坐标测量才能得精确值"。

## 口径冲突处理原则

| 冲突类型 | 处理 |
|---|---|
| 续航（官方 vs 早期媒体） | 取官方上市稿/发布会，注明另有说法 |
| 风阻/涉水（新款 vs 现款官网） | 取新 M8 发布会口径，注明现款值 |
| 整备质量（现款参数页 vs 工信部新款） | 新款电池加大，取工信部新款口径 |
| 电机功率（不同年款） | 取发布会一手数据 |

**一手优先级**：发布会视频转录 > 官方上市稿 > 工信部公告 > 汽车之家等参数页 > 早期媒体报道。
