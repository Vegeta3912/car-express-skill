# 工信部《公告》参数怎么定位

> 前悬/后悬、轴荷、轮距、整备质量、总质量、接近/离去角、额定载客——这些只有《公告》有原值。
> 官网只给外形尺寸，汽车之家/易车没有前悬后悬与轴荷，媒体稿只转引部分字段。

## 一、系统在哪

**道路机动车辆生产企业及产品信息查询系统**（工信部装备工业发展中心主办，免费公开，173 批至今）

```
https://service.miit-eidc.org.cn/miitxxgk/gonggao/xxgk/index
```

三个入口别用错：

| 入口 | 用途 | 注意 |
|---|---|---|
| 产品信息（默认） | 查**当前有效**公告 | 只返回最新状态，停产/撤销型号查不到 |
| 产品分批查询 | 按批次查历史产品 | 适合确认"哪一批申报的" |
| 公告数据 | 批量下载 | 需登录，一般不用 |

## 二、定位一台车：先型号、后批次

公告是按**车辆型号**（如 `SKE6522DBEVR1`、`QCJ6520BUBEV3`）组织的，不是按商品名。商品名"问界 M8""腾势 N8"在系统里搜不到，只能搜**企业名/品牌/型号**。

推荐路径：

1. **按品牌搜**，拿到该品牌全部型号 + 批次（列表接口 `doCpQueryByeOne` 返回 JSON，自动翻页，不受频控）。
2. **看批次**判断代际：稿子写"新款/上市在即"→ 取最近 1–2 批；老款在售 → 批次会明显靠前。
3. **看外形尺寸**对号：同品牌常有多个同长车型（腾势 QCJ6520 既有 N8 也有 N8L/N9 衍生），用"长×宽×高 + 轴距"确认是哪台。
4. 一台车通常有**多个型号**（不同电池/电机/座位/配置），参数会不一样——**全部拉下来**，表里给区间，别只取一个当全系。

品牌 → 型号前缀（常见）：

- 比亚迪 / 腾势 / 方程豹：`QCJ`（腾势乘用车多为 `QCJ6xxx`、`QCJ7xxx` 轿车）
- 问界（赛力斯）：`SKE`
- 理想：`LXA`；蔚来：`HFC`；小鹏：`NHQ`；极氪：`L6T`；小米：`XMA`

拿不准就先按品牌名搜一次，型号前缀自然出现。

## 三、参数页怎么拿（关键：验证码是纸老虎）

参数页地址形如：

```
/miitxxgk/gonggao/xxgk/queryCpData?dataTag=Z&gid=<产品ID>&pc=<批次>
```

直接 GET 会命中一个**滑块验证页**。但它的校验**完全在前端**：

- `x`、`y`（拼图缺口位置）由页面 JS `random()` 当场生成，服务端不下发；
- 拖到位后只是把 `#NECaptchaValidate` 填成 65 位随机串、把"继续访问"按钮解锁；
- **服务端只看这个字段非空**。

所以：GET 一次拿到验证页 → 直接 `POST queryCpData`，带上 `dataTag / gid / pc / NECaptchaValidate=<任意 65 位串>`，就能拿到参数页 HTML。用 `scripts/miit_gonggao.py` 一行搞定。

**频控是真陷阱**：连续抓约 8 次会返回"访问频率过高，禁止访问"，封约 3 分钟。规则：

- 相邻两次参数页请求间隔 **≥25 秒**（脚本已内置）；
- 批量拉多型号时先想清楚要哪几个，别把整页都刷一遍；
- 被封就等 3 分钟再继续，不要换 UA 硬刚（封的是 IP）。

## 四、参数页上要抄哪些字段

| 字段 | 为什么架构报告需要 |
|---|---|
| 外形尺寸长/宽/高 | 与官网核对，判代际 |
| 轴距 | 一切布置推算的基准 |
| **前悬/后悬** | 前悬定动力总成与前碰吸能空间、L113 下限；后悬定三排腿部与行李厢；前悬+轴距+后悬=车长，可自洽校验 |
| **轴荷（前/后）** | 满载前后分配，判断前后配重与驱动形式倾向；前轴荷受增程器/前电机影响明显 |
| 前/后轮距 | 轮距差反映轮眉造型与横向稳定裕度 |
| 整备质量 / 总质量 | 轻量化与载重能力；总质量−整备=载客+行李 |
| 接近角/离去角 | 与前后悬、离地间隙互相印证（可反推保险杠下沿离地） |
| 额定载客 | 五座/六座/七座合规版本 |
| 轮胎规格 | 反推轮胎直径，供 A 类推算 |
| 备注 | 电池类型、电机型号/功率、选装件、是否双电机/三电机 |

## 五、两条自洽校验（必做）

1. **前悬 + 轴距 + 后悬 = 车长**。不等就是抄错型号或抄错字段（改款车长常变、悬不变）。
2. **前轴荷 + 后轴荷 = 总质量**。相等说明取的是满载轴荷；差很多说明混了不同配置。

轴荷是**满载**轴荷，不是空载配重。写进报告时说"满载轴荷"，别直接说"前后配重 43:57"；要说配重，就写"前轴占比"，并注明是满载状态。

## 六、口径优先级

```
《公告》参数页  >  官网车型页  >  汽车之家/易车参数库  >  媒体转引稿
```

- 媒体稿（易车、黑龙江网等）转引的"前悬 975/后悬 1110"可以用，但**轴荷几乎不转**，必须回公告取。
- 官网与公告冲突时（常见于整备质量、续航），报告里并列标注，取官方发布会口径，脚注说明差异。
- 公告是"型号级"数据：同一商品名多型号 → 表里给区间，脚注写清对应型号。

## 七、命令速查

```bash
# 1. 该品牌全部公告型号（含批次、gid）
python3 scripts/miit_gonggao.py search 腾势

# 2. 按型号前缀逐条取参数（内置 25s 间隔 + 自洽校验）
python3 scripts/miit_gonggao.py model SKE6522

# 3. 取单个产品全字段
python3 scripts/miit_gonggao.py param Z AC180229 411
```

实测样例（2026-11）：

- 问界新 M8（410 批）`SKE6522DBEVR1` 纯电：5190×1999×1795，轴距 3105，前/后悬 975/1110，轴荷 1356/1779，整备 2585/2685，总质量 3135
- 问界新 M8（410 批）`SKE6522DREEVR1` 增程：轴荷 1511/1749，整备 2725/2810，总质量 3260
- 腾势 N8（411 批）`QCJ6520BUBEV3` 三电机：5150×1999×1820，轴距 3075，前/后悬 985/1090，轴荷 1579/1906，整备 2995/3030，总质量 3485
