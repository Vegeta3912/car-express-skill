# 版式设计系统 · 必须遵守

本 skill 的样式不靠每次重写 CSS，而是直接复用 `assets/report-template.html` 里的完整 `<style>` 与 `<script>`（逐字节保留）。**不要另写 CSS**，只需按下面规范往骨架里填内容，即可得到一致的版式。

## 排版层次（靠排版建立，不要用框）

层级体系：**章头 → 章导语 → 小节标题 → 正文 → 表格/图/脚注**。用户要"层次清晰"，不是"层次多"。

1. **章头** `.ch-head`：巨型品红章号（54–84px）+ 英文标签 `.ch-tag`（深色胶囊）+ 中文标题 `h2`（32–52px）+ 副标题 `.sec-sub`（14px 灰）。
2. **章导语** `<p class="lead">`：每章开头一段，18.5px、加粗、深色、下方 1px 分隔线，作全章总纲。**不要把分析/判断单独做成"框"**——用户明确反感，判断直接写进正文。
3. **小节标题** `h3`：21–27px + 品红左边条 + 编号（如"1.2 布置硬点推算值"）。
4. **正文** `p`：17px，行高 1.95。关键术语/结论用 `<strong>` 加粗。
5. **表格** `.tblwrap > table`：所有数据一律进表格；表头浅灰底、数字右列 `td.num` 等宽加粗；口径说明用 `<sup>[n]</sup>` 信源上标、`.tag-est`（区间估算）、`.tag-off`（官方）小标签。**第 1 章固定两张表**：1.1 配置版本（动力/座椅×版本×起售价×关键差异）、1.2 基础参数总表（参数项尽量多：尺寸/轴距/前后悬/轮距/角度/离地/风阻/质量/轮胎/涉水/容积/0-100/快充/对外放电/馈电油耗/悬架/电池）。
6. **对标表** `.tblwrap > table.cmp`（第 5 章）：四列＝维度 / 目标车 / 对标车 / 优势方。优势方用 `td.adv-a`（品红＝目标车优）、`td.adv-b`（蓝＝对标车优）、`td.adv-tie`（灰＝持平）。表格 `min-width:640px`、第一列 `white-space:nowrap`，窄屏在容器内横向滚动。表下脚注写两车来源 + "优势方仅就单项硬指标而言，不代表整车优劣"。**不要另写"我方领先项/对方领先项"清单**，会与表格重复。
7. **图片** `.figure`：一律放对应正文段落之后（先文字后图），统一图注 `.cap`（"图 X.Y · 画面描述。来源：… [n]"）。两张并排用 `.fig-row`。
8. **脚注** `.footnote`：13px 灰字，放表格/段落下方，写方法与口径说明。推算小节的方法与过程也降级为脚注，不占正文。

## 留白（舒展，宁松勿紧）

- 章节上下 padding ≥ 80px
- `h3` 上下 ≥ 50/20px
- 正文行高 1.9+
- 表格 `td` padding ≥ 16px
- 章导语 `padding-bottom` ≥ 28px

## 背景质感

多层 `radial-gradient` 光泽 + 极淡 `repeating-linear-gradient(112deg,…)` 丝绸质感，**不用硬朗的重复斜杠条纹**（`.watermark` 已实现，勿改）。

## 水印

- 左上角的 logo 图（多为浅灰底彩字）：`mix-blend-mode:multiply` 融入；`position` 随顶栏固定在左上角；窄屏 `@media(max-width:640px)` 隐藏文字、图缩到 58px。
- 正文内不另行叠加图片水印，避免遮挡文字。

## 交互

- 目录点击为**原生锚点跳转**，CSS 里**不要** `scroll-behavior:smooth`（要瞬时到位，不要滚动动画）。
- 保留 `scroll-margin-top:78px`（让标题停在顶栏下方不被遮挡）。
- 侧栏目录 sticky + 滚动高亮（脚本已实现）；窄屏可展开抽屉（脚本已实现）。

## 单文件离线

先写带 `__IMG_xxx__` 占位符的骨架，再用 `scripts/inline_images.py` 把图片压到合适宽度转 base64 注入。成品 HTML 样式/脚本/图片全内联，双击即可离线打开。
